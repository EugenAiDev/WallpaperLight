# Публикация исходников

Репозиторий подготовлен локально на ветке `main`. Исходники добавлены в index; первый commit и push ещё не выполнены. Удалённый репозиторий не задан.

1. Проверьте `git status` и `git diff --cached --stat`.
2. Убедитесь, что в Git настроены ваше имя и email для коммитов.
3. Создайте первый коммит: `git commit -m "Initial Wallpaper Light portable application"`.
4. Создайте пустой репозиторий на выбранном Git-хостинге.
5. Подключите его: `git remote add origin <URL-репозитория>`.
6. Отправьте ветку: `git push -u origin main`.

На GitHub workflow `Windows build` проверяет исходники и собирает автономный ZIP. Проверка интеграции с физическими мониторами выполняется отдельно на пользовательском компьютере, в CI не запускается.

Для распространения программы прикрепите `WallpaperLight-win-x64-self-contained.zip` и файл `.sha256` к релизу. ZIP, локальные настройки, диагностические файлы и SDK исключены из Git. Исходный рабочий промпт также остаётся локальным.
