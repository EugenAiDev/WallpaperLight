Wallpaper Light — Windows 11 x64

1. Распакуйте весь архив в папку с правом записи (например, Documents\WallpaperLight).
2. Запустите WallpaperLight.exe. Установка и отдельный .NET не нужны.
3. В настройках выберите папки горизонтальных и вертикальных изображений.

Крестик скрывает окно в трей. Двойной щелчок по значку открывает окно.
Для завершения выберите «Выход» в меню трея.
При запуске в трей окно открывается только из трея; повторный EXE его не показывает.
Автозапуск при входе в Windows включается в настройках, по умолчанию выключен.
Перед переносом приложения выключите автозапуск; после переноса включите снова.
Настройки находятся в data\settings.json рядом с EXE.

Версия не подписана цифровым сертификатом.
Содержит компоненты Microsoft .NET; их лицензии и уведомления находятся рядом.
Автосмена включена по умолчанию: 30 минут. В настройках доступны 60 минут,
свой интервал 1–1440 минут и случайные 1–60 минут. После сна первая смена
через случайные 1–30 минут, затем выбранный интервал. Пауза — в окне и трее.
