# Автосмена и интерфейс v0.2.0 — 2026-10-06

- Автосмена включена по умолчанию: 30 минут; также 60, свои 1–1440 и случайные 1–60 минут.
- Таймер использует монотонное время. Просроченный tick вызывает один проход, без серии пропущенных смен. Пауза сохраняется в JSON.
- WM_POWERBROADCAST: suspend останавливает расписание; автоматический resume создаёт задержку 1–30 минут; последующее уведомление интерактивного resume не сбрасывает её. Завершение старой асинхронной операции не заменяет новое расписание.
- Таймер ждёт закрытия настроек и окончания текущей операции. Папки и порядок выбора независимы для каждого монитора.
- В режиме скрытого старта форма и кнопка панели задач не показываются. Повторный запуск не раскрывает такую форму, открытие доступно из трея.
- 28 автоматических проверок, включая моделирование времени и сна, сохранение/миграцию настроек, скрытую форму и автосмену двух мониторов через fake service.
- Проверка чтения реальных мониторов прошла. Автоматические тесты не меняют реальные обои или реестр.
- Светлая и тёмная темы, обычный/минимальный размер: отрисованы настоящие тестовые формы через DrawToBitmap и осмотрены PNG. Артефакты создаются через `WallpaperLight.Checks.exe --render-ui <папка>`; тестовые пути не относятся к личным данным.
- Computer Use недоступен из-за ошибки запуска sandbox helper. Клики в реальном трее, физический сон/гибернация и реальная перезагрузка в этой итерации не проверялись. Рамка DWM не воспроизводится точно методом DrawToBitmap.
- Автономная сборка установлена поверх обнаруженной portable-копии после резервного копирования. Хеш settings.json до/после совпадает. Реальный процесс v0.2.0 работает с MainWindowHandle=0; повторный запуск завершился с кодом 0, остался один скрытый экземпляр. Проверочная диагностика обновлённого EXE обнаружила два монитора.

Обработка resume соответствует документации Microsoft: https://learn.microsoft.com/windows/win32/power/pbt-apmresumeautomatic и https://learn.microsoft.com/windows/win32/power/pbt-apmresumesuspend.
