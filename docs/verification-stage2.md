# Проверка этапа 2 — 2026-09-27

## Реализовано

Две общие папки по ориентации, кэш списка файлов без подпапок, последовательный и случайный циклы, отдельная история для каждого монитора/ориентации, ручной выбор, открытие папки, смена всех экранов. Настройки сохраняются рядом с exe; выбор языка доступен в Settings.

## Сборка и тесты

- Release solution: без ошибок и предупреждений.
- Portable framework-dependent win-x64: успешно собран.
- 18 исполняемых unit-проверок, без сторонних тестовых пакетов, завершились успешно.
- Проверены defaults, сохранение/чтение, неверные значения, будущая схема без перезаписи, неизвестные JSON-поля, ограничение резервных копий, сохранность оригинала при блокировке записи.
- Проверены фильтры расширений, скрытые файлы, отсутствие рекурсии, сортировка, кэш, Refresh и отмена сканирования.
- Настоящие PNG/JPEG/BMP проходят валидацию и не остаются заблокированными; повреждённый файл отвергается.
- Проверены последовательный переход через конец, 30 случайных полных циклов без повторов, границы циклов, пустой/единственный файл, ограниченные попытки при повреждениях и повтор после Refresh.
- Проверены ручной выбор, ответвление истории после Previous, пропуск удалённых файлов, предел 50 записей, независимость мониторов/ориентаций и русские/английские ресурсы.

## Реальный COM

Повторно выполнен ранее разрешённый тест назначения копии текущего файла одному монитору. Изменение пути подтверждено, обои другого монитора сохранены, оригинальные пути обоих мониторов восстановлены.

## UI

- Проверены русский и английский интерфейсы при запуске.
- Тестовые общие папки автоматически распределились между горизонтальным и вертикальным мониторами.
- «Сменить все» при двух пустых папках показало сообщения без изменения обоев.
- Через UI выбран и сохранён Sequential для одного монитора; второй остался в Random.
- Окно Settings содержит две папки и выбор системного/русского/английского языка.
- Проверена итоговая компоновка: обе карточки с кнопками помещаются в окне.
- Ручной сценарий смены языка через модальный выпадающий список не удалось надёжно автоматизировать: инструмент терял контекст всплывающего списка. Смена ресурсов и сохранение языка проверены тестами, загрузка сохранённого языка — запуском приложения. Проверка переключения без перезапуска через UI остаётся ручной.
- Физический поворот/переподключение мониторов и полный набор DPI-масштабов не проверялись.

Тестовые настройки использовались только в build-каталоге и затем восстановлены. Пользовательская portable-версия не получает тестовые папки. При первом запуске нужно указать свои две папки в настройках.
